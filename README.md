# Pixel-Detective-by-LysterDoCoding

**Pixel Detective**

I am uploading this project since this is created between I and my classmates years ago, that we've spent a lot of time working on. These are programmed in MIT App Inventor.  
This game is all about clearing levels by guessing what pixelated object is on the screen. Each level has a new set of images to figure out, and the more you play, the harder it gets! Use your detective skills to spot clues and make your best guess.

There is also a .apk file for your download! Please enjoy this simple game! please give credit to me!
